Deskripsi Singkat Proyek
Kami membuat sebuah program penghitung jumlah bilangan prima dengan batas angka yang kita masukkan ke dalam program dengan memakai 3 metode eksekusi, yaitu sequential, OpenMP, dan OpenCL. Selanjutnya, kami membandingkan hasilnya dari ketiga metode tersebut dengan timing dan speedup.

Lankah-langkah 
1. Pastikan OpenMP dan OpenCL sudah ada di komputer anda
2. Salin file main.c ke dalam komputer anda
3. Buka MinGW64 atau compiler lainya
4. Ketik perintah berikut gcc <nama_file>.c -O3 -fopenmp -lOpenCL -o <nama_output>
5. Ketik ./app.exe
6. Masukkan batas angka bilangan prima yang anda inginkan
7. Tunggu sampai selesai dan hasilnya akan keluar
